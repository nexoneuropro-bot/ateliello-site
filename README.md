# Ateliello Uniformes e Bordados

Site institucional e de orçamento online da **Ateliello Uniformes e Bordados**.

## Estado

Este repositório foi inicializado para receber os arquivos da versão visual **Dois Universos**: **Para seu negócio** e **Para você**. O site completo deve ser enviado à raiz deste repositório, preservando a pasta `assets/`.

## Publicar gratuitamente

1. Extraia o pacote `Ateliello_GitHub_Netlify_Pronto.zip` no computador.
2. Em GitHub, clique **Add file → Upload files**, e arraste o conteúdo da pasta extraída (não o próprio ZIP).
3. Confirme que `index.html`, `style.css`, `app.js` e `assets/` estão na raiz do repositório.
4. No Netlify: **Add new project → Import an existing project → GitHub → ateliello-site**.
5. Deixe o comando de build vazio e **Publish directory** em `.`.

A prévia contém `robots.txt` para não ser indexada antes da aprovação. Confirme dados comerciais, materiais e conteúdo antes do lançamento.
